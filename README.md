# FOLIO 0.4.0 — iOS UI Edition

**FOLIO** — мобильный помощник для PDF, фотографий и сканов. На первом экране пользователь сразу видит ключевые задачи: объединить документы, превратить фото в PDF, изменить страницы или уменьшить фото/сканы.

## Важное об исходниках

Этот архив — **самостоятельный проект SwiftUI для проработки интерфейса и пользовательского сценария**, а не автоматическое обновление исходного FOLIO 0.3.0. В текущей рабочей среде прежний ZIP/Xcode-проект не был доступен. Файлы 0.3.0 не изменялись. Для точного продолжения существующего приложения интегрируйте UI-слой, руководствуясь `INTEGRATION.md`, и используйте прежнее проверенное PDF-ядро.

## Запуск на Mac

1. Установите Xcode 15 или новее.
2. Откройте `FOLIO.xcodeproj`.
3. Выберите схему `FOLIO`, симулятор iPhone с iOS 17+ и нажмите **Run**.
4. Для физического iPhone в **Signing & Capabilities** задайте свой Team и Bundle Identifier.
5. Запустите **Product → Test** для подготовленных XCTest.

**В этой среде Xcode и iOS SDK отсутствуют.** Здесь выполнены синтаксический разбор Swift и структурная проверка Xcode-проекта, но реальная сборка, проверка типов, UI-тесты и выполнение на iPhone ещё не подтверждены.

## Что реализовано в самостоятельном проекте

| Экран | Назначение |
| --- | --- |
| Главная | Поясняет назначение FOLIO, содержит две основные кнопки и 4 понятных инструмента |
| Файлы | Поиск, исходники/результаты, избранное, просмотр |
| Сборка | Выбор, перестановка, поворот, извлечение, дублирование, удаление и отмена |
| Экспорт | Имя, режим качества, желаемый размер, создание PDF |
| Результат | Фактическое имя и размер, просмотр, отправка через iOS share sheet |
| Шаблоны | 3 готовых сценария и сохранение пользовательских параметров |
| Настройки | Локальное хранение, сведения об ограничениях |

В проекте используются **SwiftUI, PDFKit, VisionKit** без внешних зависимостей. Основные операции выполняются локально. Оригиналы пользователя не перезаписываются. При сжатии режим затрагивает только фотографии и сканы, и берётся только действительно меньший итоговый файл. Для обычного PDF обещания достижения заданного размера нет.

### Известные ограничения

- Импорт до 40 МиБ на файл; сборка до 100 страниц.
- Нет OCR, редактирования текста внутри PDF, обработки подписанных PDF с гарантией сохранения подписи, облачной синхронизации и пакетной конвертации Office.
- При сборке некоторых сложных PDF возможны ограничения PDFKit; тестирование реальных форм, аннотаций и цифровых подписей обязательно.
- Сканирование VisionKit требует совместимого устройства и проверки разрешений.
- Отмена длительного экспорта между страницами пока не выведена в интерфейс; показывается блокирующий индикатор.
- Локальный индекс сохраняется атомарной записью JSON, но журнал безопасного восстановления файлов из проекта 0.3.0 **в этот автономный архив не перенесён**.
- Прототип не готов к TestFlight/App Store до компиляции, тестов и проверки Apple signing.

## Как проверить дизайн без Xcode

Откройте `Preview/FOLIO_UI_preview.html` в браузере. Это **кликабельный визуальный предпросмотр главного экрана**: кнопки и выбор файлов имитируют расположение элементов, но PDF в HTML-файле не обрабатывается. Для настоящих операций используйте iOS-приложение после сборки.

## Проверки и критерии качества

Смотрите `VALIDATION.md` и `UX_SPEC.md`. При интеграции сначала проверить сценарий **Добавить файлы → Сборка → Создать PDF → Поделиться**, затем Dynamic Type, VoiceOver, уменьшенную высоту дисплея, поворот экрана и длинные имена файлов.
