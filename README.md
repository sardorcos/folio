# FOLIO 0.6.0

**FOLIO** — приложение для iPhone: объединение PDF, фото и сканы в PDF, распознавание текста (OCR), изменение порядка и поворот страниц, уменьшение размера и отправка готового файла. Принимает файлы из любого приложения через «Поделиться». Всё работает на устройстве, без серверов и сбора данных.

Версия 0.6.0 — это 0.4.0 после аудита и исправлений для App Store (0.5.0) плюс OCR и расширение «Поделиться». Полный список изменений: [`CHANGELOG.md`](CHANGELOG.md). Шаги до публикации: [`RELEASE_CHECKLIST.md`](RELEASE_CHECKLIST.md).

> **Статус проверки.** Код написан и проверен статически (синтаксис Swift, структура Xcode-проекта, ресурсы). **Сборка в Xcode, unit-тесты и запуск на iPhone ещё не выполнялись**: в среде, где готовилась версия, нет macOS и Xcode. Первый шаг на Mac — собрать проект и прогнать тесты (см. ниже).

## Требования

- Mac с **Xcode 26** или новее. С апреля 2026 App Store принимает только сборки на iOS 26 SDK.
- iOS 17.0+ на устройстве (минимальная версия).
- Внешних зависимостей нет: SwiftUI, PDFKit, Vision, VisionKit, PhotosUI.

## Запуск

1. Откройте `FOLIO.xcodeproj`.
2. Проект FOLIO → **Build Settings** → **FOLIO_APP_BUNDLE_ID**: замените `com.example.folio` на свой идентификатор. Из него получаются Bundle ID всех targets (`<id>`, `<id>.share`, `<id>.tests`) и App Group (`group.<id>`).
3. Targets **FOLIO**, **FOLIOShare**, **FOLIOTests** → **Signing & Capabilities**: выберите свой **Team**. Xcode сам зарегистрирует App Group для приложения и расширения. Сами Bundle ID не меняйте: они берутся из `FOLIO_APP_BUNDLE_ID`.
4. Выберите симулятор iPhone и нажмите **Run** (⌘R).
5. **Product → Test** (⌘U) — 36 unit-тестов: импорт, экспорт, порядок и поворот страниц, сжатие, OCR, пароль PDF, общая папка «Поделиться», поиск по тексту, восстановление библиотеки, склонения. Тесты OCR пропускаются (Skipped), если Vision недоступен в симуляторе: проверьте их на iPhone.
6. Сканер и расширение «Поделиться» проверяйте на настоящем iPhone. В симуляторе камеры нет. Расширение проще всего проверить так: установить FOLIO, затем в «Фото» или «Файлах» нажать «Поделиться» → FOLIO. Для отладки подойдёт схема FOLIOShare: Xcode создаёт её автоматически и при запуске спрашивает приложение-источник.

Проект использует синхронизируемые папки Xcode 16+: любой файл, добавленный в `FOLIO/` или `FOLIOTests/`, попадает в сборку автоматически, править `project.pbxproj` вручную не нужно.

## Сборка без Mac: Codemagic → TestFlight

Каждый push в `main` собирается в Codemagic и отправляется в TestFlight (`codemagic.yaml`). Разовая настройка Apple Developer, App Store Connect и Codemagic описана в [`CODEMAGIC.md`](CODEMAGIC.md).

Перед отправкой в App Store:

```bash
python3 scripts/release_check.py
```

Скрипт проверяет структуру проекта, иконку, манифест конфиденциальности и каталог строк, а также напоминает о незаполненных Bundle ID, Team и ссылках поддержки.

## Структура

```
FOLIO/
  App/          FOLIOApp, AppConfig (ссылки на политику и поддержку — заполнить!)
  Models/       Документы, лимиты, ошибки, качество, шаблоны, склонения
  Services/     FolioStore (состояние и хранилище), PDFWorker (PDF-ядро),
                TextRecognizer (OCR), ThumbnailRenderer (миниатюры), FolioScannerView (камера)
  Screens/      Главная, Файлы, Сборка, Экспорт, Результат, Документ, Шаблоны, Настройки
  Design/       FolioTheme: адаптивные цвета, кнопки, компоненты
  Resources/    Assets (AppIcon, AccentColor), Localizable.xcstrings, PrivacyInfo.xcprivacy
FOLIOShare/     Расширение «Поделиться»: принимает PDF и изображения из других приложений
Shared/         Код, общий для приложения и расширения (общая папка App Group)
Config/         Entitlements (App Group) и Info.plist расширения
FOLIOTests/     Unit-тесты и генератор тестовых PDF/изображений
scripts/        release_check.py
Preview/        HTML-макет главного экрана (без обработки PDF)
```

## Что умеет приложение

| Экран | Возможности |
| --- | --- |
| Главная | Добавить файлы, сканировать, 4 быстрых сценария, продолжение черновика, недавние |
| Файлы | Поиск по названию **и тексту внутри документов**, фильтры, сортировка, избранное, переименование, удаление |
| Сборка | Перетаскивание страниц, стрелки, поворот, дублирование, удаление, «оставить только выбранные», отмена |
| Экспорт | Имя файла, 3 режима качества, желаемый размер с реальным подбором сжатия |
| Результат | Фактический размер, пояснение по сжатию, «Поделиться / Сохранить в Файлы» |
| Документ | Просмотр, «Текст документа» (выделить, скопировать, отправить), «Распознать текст» для PDF-сканов |
| Шаблоны | 3 готовых сценария и свои шаблоны (качество + размер) |
| Настройки | Переключатель OCR, хранилище, ограничения, политика конфиденциальности, поддержка, версия, удаление всех данных |
| «Поделиться» | В любом приложении: «Поделиться» → FOLIO. При открытии FOLIO файлы попадают в редактор (если черновик пуст) или в «Мои файлы» |

### Распознавание текста (OCR)

- Работает через Apple Vision на устройстве, без сети. Языки: русский и английский.
- Фото и сканы распознаются при добавлении: в PDF добавляется невидимый слой текста. Документ выглядит как раньше, но текст можно искать, выделять и копировать в любом PDF-просмотрщике.
- Для PDF, которые уже являются сканами, есть действие «Распознать текст»: создаётся копия с текстом, оригинал не меняется. Страницы, где текст уже есть, копируются без изменений.
- В режиме «Максимальное сжатие» текст распознаётся заново, поэтому сжатый PDF остаётся доступным для поиска.
- Выключается в Настройках. Распознавание занимает примерно 0,5–1 с на страницу; прогресс показывается.

### Расширение «Поделиться»

- Расширение только копирует файлы в общую папку App Group (`group.<bundle id>/Inbox`) и ничего не обрабатывает. Так оно укладывается в лимиты памяти расширений.
- Пакет файлов становится видимым приложению одной атомарной операцией, поэтому недописанный файл не может быть импортирован.
- FOLIO забирает файлы при запуске и при каждом возвращении в приложение. Расширения «Поделиться» по правилам iOS не могут сами открыть приложение, поэтому пользователь видит подсказку «Откройте FOLIO».

### Ограничения

- PDF до 200 МБ, изображение до 50 МБ, до 500 страниц в одном PDF.
- Сжатие уменьшает только растровые страницы (фото, сканы). Режим «Максимальное сжатие» превращает все страницы в изображения: текст перестаёт выделяться — интерфейс предупреждает об этом.
- При пересборке PDF интерактивные формы и цифровые подписи могут не сохраниться. Это нужно проверить на реальных документах.
- Качество OCR зависит от скана; рукописный текст распознаётся плохо.
- Нет подписи, облачной синхронизации и английской локализации — это кандидаты в следующие версии.

## Данные пользователя

Файлы лежат в `Application Support/FOLIO/Files`, список документов — в `index.json` рядом, текст для поиска — в `Text/`. Путь тот же, что в 0.4.0, поэтому установленные копии подхватят библиотеку. Если индекс повреждён, FOLIO не перезаписывает его: сохраняет копию `index.corrupted-<время>.json` и восстанавливает список по файлам.
