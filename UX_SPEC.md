# UX-спецификация FOLIO 0.4: «Понятно с первого экрана»

## Проблемы старого дизайна и решения

1. **Неочевидное назначение**. Показан ясный заголовок «PDF, фото и сканы. Всё в одном приложении.» и короткая строка с результатами работы.
2. **Много равнозначных кнопок**. Одно основное действие: «Добавить файлы». Второе: «Сканировать». Ниже 4 конкретных инструмента.
3. **Слишком крупные плитки**. Карточки инструментов имеют одинаковую компактную структуру: пиктограмма, действие, короткое объяснение.
4. **Неочевидные функции кнопок**. Нет абстрактных «Начать» и «Продолжить» без контекста. Применяются «Объединить PDF», «Фото в PDF», «Изменить страницы», «Уменьшить размер».
5. **Случайная потеря черновика**. При новой операции пользователь выбирает «Добавить к текущему» или «Создать новый»; черновик удаляется только после успешного нового импорта.
6. **Ошибочный статус результата**. Приложение выводит фактический размер и отдельное предупреждение, если заданная цель сжатия не достигнута.
7. **Слабая доступность**. Основные кнопки 52–54 pt, вторичные нажатия и стрелки минимум 44 pt; используется Dynamic Type, SF Symbols, системный контраст.

## Токены дизайна

- Основной цвет: `#2952E6`
- Светлый акцент: `#EAF0FF`
- Текст: `#17233D`
- Приглушённый текст: `#637084`
- Фон: системный `systemGroupedBackground`
- Поверхность: системный `secondarySystemGroupedBackground`
- Радиус основной кнопки: 15 pt; радиус карточки: 16–18 pt.
- Типографика: системный SF, динамические стили `.title`, `.title2`, `.headline`, `.subheadline`, `.footnote`.

## Основные пользовательские сценарии

**Новый документ:** Главная → Добавить файлы → Сборка → Настройки → Готовый PDF → Поделиться.

**Фото в PDF:** Главная → Фото в PDF → Выбрать изображения → Сборка → Создать PDF.

**Сканирование:** Главная → Сканировать → Сфотографировать страницы → Сборка → Создать PDF.

**Существующий черновик:** Главная → Продолжить работу → Изменить страницы → Создать PDF.

## Что проверить на устройстве

- iPhone с небольшим экраном, iPhone Pro Max, светлая/тёмная тема, системный масштаб текста 130–200%.
- VoiceOver: объявление назначения кнопок и последовательности страниц.
- Длинные кириллические названия и имена с несколькими точками.
- Объединение PDF, проверка числа страниц и сохранение исходников.
- Возврат после системного выбора файлов, отказ доступа к камере, отмена импорта.
- Повторное открытие файла после переименования и передачи через share sheet.
