# Изменения

## 0.5.0 — подготовка к App Store

### Блокеры публикации
- Добавлена иконка приложения (временная, 1024×1024, без прозрачности) и подключена в сборке (`ASSETCATALOG_COMPILER_APPICON_NAME`).
- Проект пересобран в формате Xcode 16+ (синхронизируемые папки) под Xcode 26. `SWIFT_VERSION = 5.9` заменён на допустимое `5.0`.
- В Debug включён `ENABLE_TESTABILITY` (без него `@testable import` не собирался); у тестов появилась зависимость от приложения.
- В Release создаются dSYM (`dwarf-with-dsym`), чтобы читать отчёты о сбоях.
- Добавлены `PrivacyInfo.xcprivacy` (UserDefaults, CA92.1; трекинга и сбора данных нет) и `ITSAppUsesNonExemptEncryption = NO`.
- Из настроек убран текст «Демонстрационный iOS-проект…». Добавлены версия, ссылки на политику конфиденциальности и поддержку (`AppConfig.swift`).
- Bundle ID заменён на нейтральный `com.example.folio`: его нужно заменить на свой.

### Потеря данных и неработающие функции
- **Повреждённый индекс больше не затирает библиотеку**: старый файл сохраняется как `index.corrupted-<время>.json`, список документов восстанавливается по файлам в хранилище.
- Файлы, оставшиеся без записи в индексе после сбоя, возвращаются в библиотеку при запуске.
- Импорт и экспорт пишут сначала во временную папку и переносят в библиотеку только готовый файл.
- **Поворот страницы виден на миниатюре.**
- **«Желаемый размер» работает**: в режимах сжатия FOLIO перебирает уровни качества, пока не уложится в цель, и никогда не выдаёт файл больше несжатого. В режиме «Исходное качество» честно предупреждает.
- **Качество экспорта не «залипает»**: каждая задача и каждый шаблон задают свои настройки.
- **Удаление документов**: свайпом, из меню, с экрана документа; «Удалить все документы» в настройках. Страницы удалённого документа убираются из черновика и из истории отмены.
- Ошибка «больше 100 страниц» больше не выдаётся за «файл больше 40 МБ».

### PDF и импорт
- «Фото в PDF» открывает галерею «Фото» (PhotosPicker, без запроса разрешений) с сохранением порядка выбора.
- Страницы из фото и сканов вписываются в A4 (или Letter для США/Канады и др.), а не создаются размером в метр. Ориентация EXIF применяется. JPEG встраивается без повторного сжатия.
- Поддерживаются все изображения, которые читает iOS (HEIC, HEIF, TIFF, WebP и т. д.); тип определяется по содержимому, а не по расширению.
- Файлы iCloud Drive, ещё не скачанные на устройство, загружаются через `NSFileCoordinator`.
- PDF с паролем: FOLIO спрашивает пароль и сохраняет в библиотеке копию без пароля, оригинал не меняется.
- Новый режим «Максимальное сжатие» для сканов, присланных в виде PDF (с предупреждением, что текст перестанет выделяться).
- Работает отмена импорта и экспорта (кнопка «Отменить»); при сворачивании приложения операция получает время на завершение.
- В итоговый PDF записываются название и создатель.
- Лимиты подняты: PDF до 200 МБ, изображение до 50 МБ, до 500 страниц в одном PDF.

### Интерфейс
- Нативная навигация: у каждой вкладки свой `NavigationStack`, системные заголовки, поиск `.searchable`, списки со свайпами.
- Перетаскивание страниц в редакторе, контекстное меню страницы («В начало», «В конец» и др.), «Выбрать все».
- Подтверждение для «Оставить только выбранные».
- Миниатюры рисуются вне главного потока с кэшем: редактор не тормозит на больших документах.
- Тёмная тема: все цвета адаптивные, контраст по WCAG AA. AccentColor с тёмным вариантом.
- Неактивные кнопки выглядят неактивными.
- Dynamic Type: на крупном шрифте кнопки и сетки перестраиваются в колонку.
- VoiceOver: признак «выбрано» у страниц и вариантов, действия «переместить раньше/позже», заголовки разделов.
- Правильные склонения: «1 страница / 3 страницы / 5 страниц» (String Catalog).
- Сканер открывается на весь экран; при запрете доступа к камере предлагается открыть Настройки; ошибки камеры показываются.
- Отправка через системный `ShareLink` с понятным именем файла.
- Экран результата: «Готово» возвращает на главную, повторное создание PDF по ошибке исключено.
- Шаблоны создаются в отдельной форме с выбором качества и размера.
- Размер «МБ» везде считается одинаково (1 МБ = 1 000 000 байт, как показывает iOS).

### Тесты и инструменты
- 25 unit-тестов вместо 5: импорт (PDF, фото, EXIF, пароль, лимиты), экспорт (порядок, поворот, имя, сжатие), хранилище (перезапуск, восстановление индекса, удаление, отмена), шаблоны, склонения. Хранилище подменяется временной папкой, данные приложения не затрагиваются.
- `scripts/release_check.py` — проверка готовности к релизу. Удалены самописный генератор `project.pbxproj` и устаревшие VALIDATION/INTEGRATION.
