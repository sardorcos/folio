# Как внедрить новый дизайн в существующий FOLIO 0.3.0

Исходники FOLIO 0.3.0 не были доступны в текущей среде. Следующая схема намеренно не предлагает заменить старое приложение целиком.

## Перенос по компонентам

1. Скопируйте `FOLIO/Design/FolioTheme.swift` в существующий Xcode-проект. Проверьте конфликтующие имена.
2. Скопируйте `FOLIO/Screens/FolioHomeView.swift` и переподключите действия `store.openImporter`, `store.continueDraft`, `store.showingScanner` к реальным методам вашей версии `DocumentStore`.
3. Перенесите `FolioFileRow` и сетку быстрых инструментов в существующую библиотеку. Не заменяйте поддержку корзины, избранного и сортировок из версии 0.3.
4. Для редактора страниц возьмите систему кнопок из `FolioComposerView.swift`, но используйте уже существующую логику поворотов, Undo, восстановления и пакетного выделения из 0.3.
5. Для экспорта сохраните прежнее PDF-ядро и журнал файловых операций; используйте обновлённые тексты, качественные параметры, `safeAreaInset` и подтверждённое имя файла.
6. Добавьте диалог выбора при существующем черновике: «Добавить в текущий» или «Начать новый». Существующий черновик нельзя очищать до успешного импорта.
7. Удалите любые вторые первичные CTA на одном экране; основные кнопки должны иметь целевую высоту не менее 44 pt.

## Матрица соответствия действий

| Новый UI | Ожидаемое действие iOS 0.3 |
| --- | --- |
| Добавить файлы | Вызов существующего fileImporter, сохраняющего исходники |
| Сканировать | Вызов VisionKit камеры |
| Объединить PDF | Выбор нескольких PDF и переход в редактор |
| Фото в PDF | Импорт JPEG/PNG/HEIC и создание PDF-страниц |
| Изменить страницы | Открыть действующий черновик или выбрать PDF |
| Уменьшить размер | Настройки экспорта, без обещания достижения лимита |
| Далее: сохранить PDF | Создать результат, сохранить оригиналы |
| Поделиться | Системная панель с пользовательским именем PDF |

## Правила безопасности

- Не перезаписывать файлы исходников.
- Не подменять настоящее сжатие изменением числа в интерфейсе.
- Не скрывать выбор дополнительных файлов, если уже есть черновик.
- Сохранить пользовательские метаданные и формат индекса из 0.3.0 при миграции.
- Для тестирования использовать обезличенные образцы документов.
