# Чек-лист публикации FOLIO в App Store

Отмечайте по порядку. Пункты 1–3 делаются на Mac в Xcode 26.

## 1. Сборка и тесты
- [ ] Открыть `FOLIO.xcodeproj` в **Xcode 26+**. Если Xcode предложит обновить настройки проекта, согласиться.
- [ ] **Signing & Capabilities** (targets FOLIO и FOLIOTests): выбрать Team, задать свой Bundle ID вместо `com.example.folio` (например, `ru.<компания>.folio`).
- [ ] Собрать (⌘B). Исправить ошибки компиляции, если появятся: код проверен только статически.
- [ ] Прогнать тесты (⌘U): все 25 должны пройти. Если не проходит `testRussianPluralForms`, проверить, что `Localizable.xcstrings` входит в target FOLIO.
- [ ] Убедиться, что `Localizable.xcstrings` после сборки заполнился строками интерфейса (Xcode извлекает их автоматически).
- [ ] `python3 scripts/release_check.py`: без ❌.

## 2. Заполнить данные
- [ ] `FOLIO/App/AppConfig.swift`: настоящий URL политики конфиденциальности и e-mail поддержки, затем удалить строку `#warning`.
- [ ] Опубликовать политику конфиденциальности (например, на сайте или в GitHub Pages). Суть для FOLIO: данные не собираются, файлы обрабатываются и хранятся только на устройстве, доступ к камере нужен только для сканирования.
- [ ] Заменить временную иконку `AppIcon.png` финальной: 1024×1024, PNG, без прозрачности и скруглений. По желанию добавить тёмный и tinted варианты.
- [ ] Версия: `MARKETING_VERSION` (например, 1.0.0) и `CURRENT_PROJECT_VERSION` (увеличивать при каждой загрузке).
- [ ] Проверить, что название «FOLIO» свободно в App Store; при необходимости добавить подзаголовок (например, «PDF, фото и сканы»).

## 3. Ручная проверка на iPhone
- [ ] Главный сценарий: Добавить файлы → Сборка → Создать PDF → Поделиться → Сохранить в «Файлы». Открыть результат в другом приложении.
- [ ] Фото в PDF (10+ фото из галереи), порядок страниц совпадает с порядком выбора.
- [ ] Сканирование: первый запуск (запрос разрешения), отказ (диалог с переходом в Настройки), повторное разрешение.
- [ ] PDF с паролем: верный пароль, неверный пароль, «Пропустить».
- [ ] PDF из iCloud Drive, которого нет на устройстве.
- [ ] Перетаскивание, поворот, дублирование, удаление, «Отменить».
- [ ] Сжатие: фото-PDF с целью 2 МБ; обычный текстовый PDF в режиме «Исходное качество» с целью (должно быть предупреждение).
- [ ] Отмена долгого экспорта (100+ страниц), сворачивание приложения во время экспорта.
- [ ] Удаление документа, который используется в черновике; «Удалить все документы».
- [ ] Тёмная тема, Dynamic Type до максимального (AX5), VoiceOver на главной и в редакторе, iPhone SE и Pro Max, альбомная ориентация.
- [ ] Реальные PDF с формами, аннотациями и цифровыми подписями: решить, нужно ли предупреждение в интерфейсе.
- [ ] Обновление поверх 0.4.0 (если она стояла у тестировщиков): библиотека и черновик сохранились.

## 4. TestFlight
- [ ] Product → Archive → Distribute App → App Store Connect.
- [ ] Внутреннее тестирование, затем внешнее (для внешнего нужна короткая бета-проверка Apple).
- [ ] Собрать отзывы, исправить, повторить архив с новым build number.

## 5. App Store Connect
- [ ] Новое приложение: Bundle ID, основной язык — русский, категория «Производительность» (дополнительно «Бизнес» или «Утилиты»).
- [ ] **Privacy Policy URL** и **Support URL** обязательны.
- [ ] **App Privacy**: «Data Not Collected» (FOLIO не собирает данных). Ответ должен совпадать с `PrivacyInfo.xcprivacy`.
- [ ] **Age Rating**: заполнить анкету (для FOLIO все ответы «Нет» → 4+).
- [ ] Экспортный контроль: ответ уже задан в Info.plist (`ITSAppUsesNonExemptEncryption = NO`).
- [ ] Скриншоты iPhone 6,9″ (1320×2868 или 1290×2796): главная, сборка страниц, экспорт со сжатием, результат, тёмная тема. Без макетов чужих устройств и логотипов.
- [ ] Описание, ключевые слова (PDF, объединить, сканер, фото в PDF, сжать PDF), промо-текст.
- [ ] Цена и доступность (страны).
- [ ] Заметки для ревьюера: приложение работает без аккаунта; для сканирования нужна камера; тестовые PDF можно создать из фото.
- [ ] Отправить на ревью.

## Частые причины отказа и как они закрыты
| Правило | Риск | Статус |
| --- | --- | --- |
| 2.1 Полнота | Демо-тексты, заглушки, неработающие кнопки | Демо-текст удалён, «желаемый размер» работает |
| 2.3 Метаданные | Скриншоты не соответствуют приложению | Снимать с реальной сборки |
| 4.3 Спам | Много похожих PDF-приложений | Нужна изюминка в описании: всё на устройстве, без подписки и рекламы, понятный сценарий. В планах OCR |
| 5.1.1 Конфиденциальность | Нет политики, неверный App Privacy | Ссылка в настройках, манифест, «Data Not Collected» |
| 5.1.1 Разрешения | Расплывчатое описание доступа к камере | Текст объясняет, зачем нужна камера |
